# CS Portfolio

My Southern New Hampshire University Computer Science portfolio featuring programming projects and reflections.

## IT 230 — Software Development

### Project Overview

For my IT 230 final project, I developed two versions of a student course registration application using C#. The first was a console application, and the second was a Windows Presentation Foundation (WPF) application. Both applications were designed to help students select and register for courses while preventing duplicate registrations and enforcing a maximum of nine credit hours.

### What I Did Well

One area where I feel I did particularly well was implementing the registration validation. Both applications needed to recognize valid courses, prevent students from registering for the same course twice, and stop additional registrations once the nine-credit-hour limit was reached. I tested different scenarios to make sure these requirements worked correctly.

### Console Application vs. WPF Application

The console application used text-based menus and keyboard input to allow students to select courses. It displayed confirmation messages, error messages, and the student's current registration directly in the console.

The WPF application provided a graphical user interface with a course selection dropdown, registration button, list of registered courses, and total credit hours display. I think the WPF design was more user-friendly because students could select courses without memorizing menu numbers, and the interface displayed their registration information in an organized way. Both designs accomplished the same goal, but the WPF version made the process more visual and interactive.

### Debugging and Coding Strategies

Throughout this project, I used Visual Studio to identify coding errors, make corrections, and test the applications. I worked through problems one step at a time and tested different registration scenarios to verify that the programs behaved correctly.

I learned that debugging requires patience and attention to detail. Checking method names, conditions, and program output helped me understand how different parts of the code worked together. These are strategies I plan to continue using in future programming projects.

### Overcoming Challenges

One of my biggest challenges was transitioning from a console-based program to a graphical WPF application. I had to understand how user interface controls interacted with the C# code and how button events could trigger registration logic.

I approached this challenge by breaking the application into smaller tasks, testing each feature, and making adjustments when something did not work as expected. I also learned how to use validation messages to provide helpful feedback to users. Completing both applications helped me become more confident in my programming and problem-solving abilities.

### Final Reflection

This project helped me develop a better understanding of C# programming, debugging, object-oriented programming, and user interface design. It also showed me the importance of testing software from the user's perspective.

I plan to build on these skills as I continue my Computer Science degree and work toward developing more advanced applications.
